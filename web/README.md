# Frontend

Web app that visualizes the alerts produced by the backend. Vite + React + TypeScript.

## Requirements

- **Node.js 20 or newer** ([download](https://nodejs.org)). It ships with `npm`, the only tool used here.

## How to run

All three commands, from the repository root:

```bash
cd src && python main.py
```

```bash
npm --prefix web install
```

```bash
npm --prefix web run dev
```

Open the URL the last command prints (usually `http://localhost:5173`).

What each one does:

1. **`python main.py`** generates the data. The web app computes nothing: it only reads the JSON files the backend writes into `public/data/`. Without this step the page loads but shows up empty.
2. **`npm install`** downloads the dependencies into `node_modules/` (React, AG Grid, ECharts...). Only needed the first time, or whenever `package.json` changes.
3. **`npm run dev`** starts the development server. Saving a file refreshes the browser on its own: no reloading and no restarting.

`--prefix web` tells npm to work on the `web/` folder even though you are at the root. If you would rather move into the folder, `cd web` followed by `npm install` / `npm run dev` is equivalent.

## The data

`public/` is the static-assets folder: whatever is inside is served as-is, without going through the compiler. That is why the JSON files live in `public/data/` and the browser requests them with a `fetch` to `./data/<file>.json`.

That folder is in `.gitignore`: the data is regenerated, not versioned.

## Other commands

```bash
npm --prefix web run build
```

Compiles the app into static files under `dist/`. It also type-checks the TypeScript, so it fails on any typing error (`npm run dev` does not: it favours speed). This is what gets deployed to GitHub Pages.

```bash
npm --prefix web run preview
```

Serves the contents of `dist/` locally, to inspect the build output before deploying it. Requires having run `build` first.

## Structure

```
web/
  index.html          # Page that loads the app
  public/data/        # JSON generated by the backend (gitignored)
  src/
    main.tsx          # Entry point
    App.tsx           # Menu and routes
    lib/              # types.ts (JSON contract) + data.ts (useData hook)
    components/       # DataGrid.tsx (AG Grid) and Chart.tsx (ECharts)
    routes/           # One page per route
```

See the root `CLAUDE.md` for the architecture conventions.
